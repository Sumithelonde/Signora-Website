# Optional hero media

The website works without hero video. An original vector station illustration is used as fallback.

To enable video, supply a properly licensed and compressed `hero-station.mp4` and set `NEXT_PUBLIC_HERO_VIDEO_SRC=/media/hero-station.mp4` in `.env.local`.

Storyboard: 0–4.3s web-native opening and character-by-character headline; 4.3–10.0s station-story footage showing a platform-change announcement whose text display does not update. Never show an ISL-signing avatar or the solution in the hero.

Other research media must be team-approved, publicly shareable and accurately labelled. No binary assets are silently invented.
